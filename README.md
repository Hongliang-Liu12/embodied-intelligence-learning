## 主线与成果

| 顺序 | 阶段 | 成果 |
|---|---|---|
| 1 | A：二连杆、MuJoCo、运动学与最小控制 | P0：二连杆基础练习台 |
| 2 | B：UR5 系列、URDF、规划与控制 | P1：传统视觉抓取的机械臂部分 |
| 3 | C：相机、标定、GraspNet、抓取与仿真差距 | P1：传统视觉抓取闭环 |
| 4 | D：数据、BC、ACT、Diffusion Policy | P2：模仿学习实验 |
| 5 | E：强化学习，重点深入 SAC | P3：SAC 控制与失效分析 |
| 6 | F：VLM/VLA、LoRA、Flow Matching、π 系列 | P2：VLA 扩展 |
| 穿插 | G：C++ / Python 工程基础 | 为当前项目补必要的编码能力 |
| 最后 | H：项目整合、逐题模拟面试 | 三项主成果与可信的项目表述 |

P0–P3 是项目编号，不是额外四门独立课程，也不是优先级评级。理论和实操共同服务同一项目。

## 进度怎么记

“已讲过”“用户已完成实验”“代码已审阅”“独立验收通过”分别记录，不混为一谈。用户的完成报告可用于继续上课；尚未上传代码不表示没有完成，但也不能冒称已经独立复现。

已有 MuJoCo 8 课是 **A/P0 内的入门实操序列**，不是整条学习路线。它的 3/8 不等于总体完成 37.5%。完成这 8 课后，仍需补齐 A06 逆运动学、A07 雅可比/奇异性与 A08 控制验收中的未完成项目。

动态进度只维护在 [LEARNING_STATE.md](LEARNING_STATE.md)，不在多个首页重复统计，以免互相矛盾。

## 给教学助手与项目助手

开始教学前，读取 [AGENTS.md](AGENTS.md)、[LEARNING_STATE.md](LEARNING_STATE.md) 和当前单元。不要依靠上一段聊天的记忆猜进度，不要重新安装已成功的环境，不要因新仓库热门而换路线。

课后依据真实回答和实验更新进度，新增一份学习记录。具备仓库写权限时实际提交并提供提交链接；没有权限时说明尚未同步，并给出准确改动，不能声称已保存。

跨对话可以直接使用这句话：

> 请先读取这个仓库的 AGENTS.md、LEARNING_STATE.md 和对应项目 README，沿唯一的下一任务继续。先解释前提与默认值，再给最小实验；不要另起学习路线。

本仓库是公开仓库。不要提交服务器地址、账号、密钥、令牌、包含敏感信息的环境文件、大型数据集或模型权重。依赖版本和运行说明应保存，运行缓存与虚拟环境不入库。
