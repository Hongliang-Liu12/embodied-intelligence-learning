# A06 二连杆 IK 学习记录

日期：2026-09-16
课程：A06——二连杆 IK
项目：P0 基础练习台
证据等级：课堂问答 + 用户报告运行数学验证脚本；未独立审阅/运行其本地脚本。

## 已完成知识点

- 区分 FK 与 IK，理解位置 IK 与完整位姿 IK 的区别。
- 通过二连杆几何关系理解解析 IK。
- 理解 `theta2 = ± arccos(...)` 对应 elbow-up / elbow-down 两个分支。
- 理解 0/1/2 个几何解的情况：不可达、边界解、一般两解。
- 理解数值 IK 是从初值出发迭代逼近目标，而不是一步解析求解。
- 理解数值 IK 的误差定义在任务空间；初值、当前 Jacobian、步长、阻尼和约束影响最终收敛分支。
- 理解通常可用当前关节角作为初值以获得更连续的解。

## 数学验证实验

用户运行了 IK→FK 回代脚本，测试：

1. 目标 `(1,1)`：得到两组解析解，分别等价于 `(theta1, theta2)=(0°,90°)` 与 `(90°,-90°)`，FK 回代到同一目标。
2. 目标 `(2,0)`：代码返回两个相同/退化分支，几何上只有一个伸直解 `(0°,0°)`。
3. 目标 `(3,0)`：无解，符合 `L1+L2=2` 的可达边界。

## 课堂纠正

- `(0,2)` 对于 `L1=L2=1` 的唯一伸直解是 `theta1=90°，theta2=0°`，不是两个角都为 0。
- 任务空间误差 `e = x_target - x_current` 本身并不知道哪组关节解是 `qA/qB`；初值和局部迭代结构决定更可能收敛到附近的解分支。
- `(2,0)` 的 `+0/-0` 是解析分支在边界合并，不是两个几何上不同的解。
