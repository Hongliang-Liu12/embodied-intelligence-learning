## M04 的小步安排

第一小步只回答“允许转动”和“主动驱动”有什么区别，解释 actuator/ctrl 后，读取现有单杆代码并加一个执行器。第二小步再比较直接施加驱动与位置目标，不能同时丢一堆新参数。

每一步明确：正在控制哪个关节、ctrl 代表什么、单位是什么、重力是否启用、转轴在哪里、所用增益/gear/限幅来自显式设置还是默认继承。参数需要依据实际文件，不能仅凭总结猜测。

验收看运动过程与状态记录，不只看最终画面；直接把 qpos 写成目标值不能作为驱动器正确的证据。
