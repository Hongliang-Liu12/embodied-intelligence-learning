## 如何服务正式 A 课程

- A04 需要二连杆 FK 与仿真末端坐标数值对照时，再把模型扩成真正二连杆。
- A06 学 IK 时，先推导解析解，再用二连杆模型做 IK → FK 回代。
- A07 学 Jacobian/奇异性时，用同一二连杆比较弯曲、近伸直、伸直构型。
- A08 学控制时，用同一模型做目标跟踪、控制周期、限位与扰动实验。

因此项目不是一套独立课程，而是知识主线的实验平台。

## 实验纪律

每个实验都要明确：参考系、原点、轴、单位、默认/继承参数、输入究竟是状态还是控制命令。先预测，再修改一个变量，再运行观察。不因为示例能动就默认理解正确。
